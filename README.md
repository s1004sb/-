# 🍓 과일 스카이 레이서 🍌

뉴욕과 서울 하늘을 나는 자동차로 과일을 발사해 드론을 물리치는 3D 슈팅 게임이에요.

브라우저만 있으면 바로 플레이할 수 있어요. `index.html`을 열거나 GitHub Pages 링크로 접속하세요.

## 조작법

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| Space / 마우스 클릭 | 발사 |
| 1 / 2 / 3, Q / E | 무기 변경 |
| Shift | 부스터 |
| P | 일시정지 |

📱 휴대폰: 화면을 드래그하면 이동하고, 발사는 자동이에요.

## 과일 무기

- 🍓 **딸기**: 빠른 연사
- 🍌 **바나나**: 3갈래로 회전하며 적을 관통
- 🍉 **수박**: 느리지만 넓게 터지는 광역 폭발

## 도시

- 🗽 **뉴욕**: 엠파이어 스테이트 빌딩, 크라이슬러 빌딩, 원 월드 트레이드 센터, 자유의 여신상, 타임스스퀘어 광고판
- **서울**: 롯데월드타워, N서울타워, 63빌딩, 숭례문, 아파트 단지와 한글 네온 간판
